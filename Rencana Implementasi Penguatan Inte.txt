Rencana Implementasi: Penguatan Internal Link
TUJUAN:
Meningkatkan struktur internal linking tanpa merusak URL, tag, atau artikel yang sudah terindeks.
ANALISIS SAAT INI:
15 Artikel di _posts dengan subfolder (n8n, llm, chatbot, mcp, hosting, api, ai-agent)
7 Tags aktif: n8n, llm, chatbot, mcp, hosting, api, ai-agent
Tags page sudah ada di /tags/[tag] - berfungsi sebagai kategori
Related Posts sudah ada tapi random (bukan berdasarkan tag)
🎯 STRATEGI 1: Navigasi Artikel (Prev/Next)
Tujuan: Membantu pembaca menavigasi ke artikel sebelumnya/selanjutnya berdasarkan tanggal publikasi.
Implementasi:
✅ Buat fungsi getAdjacentPosts(slug) di lib/api.ts - mengembalikan post sebelumnya & sesudahnya berdasarkan tanggal
✅ Buat komponen PostNavigation di components/post-navigation.tsx - UI untuk prev/next dengan judul artikel
✅ Integrasikan ke app/posts/[slug]/page.tsx - tambahkan di bawah RelatedPosts
Keamanan: ✅ Hanya menambah fungsi baru, tidak mengubah URL atau struktur data yang ada.
🎯 STRATEGI 2: Sidebar Artikel Terkait (Tag-Based)
Tujuan: Menampilkan artikel dengan tag yang sama di sidebar untuk meningkatkan relevansi.
Implementasi:
✅ Buat fungsi getPostsByTagWithExclusion(tag, currentSlug, limit) di lib/api.ts - ambil artikel dengan tag sama kecuali artikel saat ini
✅ Buat komponen TagRelatedPosts di components/tag-related-posts.tsx - daftar artikel berdasarkan tag
✅ Modifikasi layout di app/posts/[slug]/page.tsx - tambahkan sidebar di bawah Table of Contents dengan section "Artikel Terkait"
Keamanan: ✅ Menggunakan data tags yang sudah ada, tidak mengubah struktur artikel.
🎯 STRATEGI 3: 'Baca Juga' Box dalam Konten
Tujuan: Menyisipkan rekomendasi artikel di tengah/bawah konten untuk engagement lebih tinggi.
Implementasi:
✅ Buat custom MDX component ReadAlso di components/mdx/read-also.tsx - box rekomendasi yang bisa disisipkan di markdown
✅ Daftarkan component di PostBody - tambahkan ke MDX components
✅ Dokumentasikan penggunaan - cara pakai: <ReadAlso slug="artikel-terkait" />
Keamanan: ✅ Optional component, penulis kontrol penuh kapan menggunakannya.
🎯 STRATEGI 4: Halaman Kategori/Topik (Hub Pages)
Tujuan: Membuat halaman khusus untuk setiap topik utama sebagai pusat konten (content hub).
Implementasi:
✅ Analisis topik utama dari 15 artikel:
- n8n (3 artikel) - Otomatisasi workflow
- LLM (4 artikel) - Local LLM, Fine-tuning, Prompting
- Chatbot (4 artikel) - Telegram bot, RAG, Python
- MCP (1 artikel) - Model Context Protocol
- Hosting (1 artikel) - VPS, Cloud
- API (2 artikel) - API LLM Gratis
- AI Agent (1 artikel) - OpenClaw
✅ Buat folder app/topics/[topic]/page.tsx - halaman dinamis untuk topik
✅ Buat konfigurasi topik di lib/topics.ts - metadata untuk setiap topik (deskripsi, icon, urutan artikel)
✅ Update navigasi - tambahkan link ke Topics di footer atau site-index
Keamanan: ✅ URL baru /topics/[topic], tidak mengganggu URL yang sudah ada (/posts/, /tags/).
🎯 STRATEGI 5: Auto-Linking System
Tujuan: Otomatis menambahkan link internal ke keyword tertentu dalam konten artikel.
Implementasi:
✅ Buat dictionary keyword-to-url di lib/internal-links.ts:
{
  "n8n": "/tags/n8n",
  "Docker": "/posts/cara-install-n8n-docker",
  "LM Studio": "/posts/cara-menjalankan-llm-laptop-kentang-offline",
  // ... dll
}
✅ Buat fungsi processContentWithInternalLinks(content) - scan konten dan ganti keyword dengan link (hanya jika belum ada link)
✅ Integrasikan di PostBody - proses konten sebelum render MDX
Keamanan: ✅ Smart detection - tidak akan mengganti text yang sudah dalam tag <a>, hanya mengganti first occurrence per artikel untuk menghindari over-optimization.
