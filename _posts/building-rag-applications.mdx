Retrieval Augmented Generation (RAG) allows you to "chat" with your own data.

## Prerequisites
- Node.js installed
- OpenAI API Key
- A Vector Database (we'll use a local instance)

## Step 1: Ingestion
First, we need to convert your PDFs into text chunks.

```javascript
import { PDFLoader } from "langchain/document_loaders/fs/pdf";
const loader = new PDFLoader("src/document.pdf");
const docs = await loader.load();
```

## Step 2: Embedding
Pass these chunks through `text-embedding-3-small` to get vectors.

## Step 3: Retrieval
When a user asks a question, we search our database for the most similar chunks and feed them to GPT-4o.

## Conclusion
RAG is powerful because it reduces hallucinations and grounds the AI in truth.
