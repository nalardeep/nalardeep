Tailwind v4 is here, and it's fast. incredibly fast.

## The Oxide Engine
Rewritten in Rust, the new CLI compiles your CSS in microseconds. It treats your files as a dependency graph.

## Zero Configuration
No more `tailwind.config.js` bloat. The engine automatically detects your content paths.

### New Features
- **CSS Containers**: Built-in support for container queries.
- **Dynamic Values**: Arbitrary values are now first-class citizens.

## Migration Guide
Upgrading is mostly seamless, but watch out for custom plugin compatibility.
