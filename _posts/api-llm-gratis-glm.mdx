# Cara Mendapatkan API LLM Gratis GLM 5.2 Via Cloudflare
Pada artikel kali ini mimin cuman pengen membagikan cara untuk mendapatkan akses gratis model GLM 5.2 Via Cloudflare Workers AI. Sebelum itu terdapat beberapa hal yang mesti dipersiapkan seperti,
1. Akun Cloudflare
2. OpenCode

Akun Cloudflare digunakan untuk mendaftar API Key yang akan digunakan, sedangkan OpenCode merupakan tools coding yang akan digunakan untuk mencoba API Key tersebut. Setelah kedua persyaratan diatas sudah dipersiapkan maka langsung dieksekusi saja

## Cara Mendapatkan Akses Gratis API LLM GLM 5.2 dengan Cloudflare
### Membuat API Key Cloudflare Workers AI
    > Sebelum mengikuti langkah langkah dibawah ini, buat akun Cloudflare terlebih dahulu.
1. Masuk ke Cloudflare
2. Pada menu build, pilih AI lalu cari bagian Workers AI.
3. Pilih Rest API
4. Kemudian Salin dan simpan Account ID terlebih dahulu.
5. Selanjutnya Create a Workers AI API Token
6. Isi nama Token dan Klik Create API Token
7. Copy API Token dan simpan 

### Menggunakan API Key Cloudflare di OpenCode
    > Sebelum mengikuti langkah-langkah dibawah ini, download OpenCode terlebih dahulu
1. Buka terminal atau PowerShell
2. Masukkan perintah Opencode
3. Untuk menghubungkan API Key, masukkan perintah **/connect**
4. Cari Cloudflare Workers AI dan enter.
5. Paste Account ID dan API Token.
6. Happy Eksperimen
