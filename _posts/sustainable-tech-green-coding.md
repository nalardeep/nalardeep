Did you know the internet emits more carbon than the airline industry?

## What is Green Coding?
It's the practice of writing code that consumes less energy.

### Strategies
1. **Optimize Images**: Use WebP/AVIF.
2. **Lazy Loading**: Don't load what the user doesn't see.
3. **Efficient Algorithms**: A `O(n^2)` loop isn't just slow; it burns coal.

## The Business Case
Green coding isn't just charity. Efficient code runs on smaller servers, saving companies millions in cloud bills.

### Languages matter
Compiled languages like Rust and C++ are vastly more energy-efficient than interpreted ones like Python.
