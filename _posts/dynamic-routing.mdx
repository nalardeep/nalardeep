# Dynamic Routing

Next.js App Router makes it easy to create dynamic routes.

```tsx
// app/posts/[slug]/page.tsx
export default function PostPage({ params }: { params: { slug: string } }) {
  return <div>My Post: {params.slug}</div>
}
```

This blog uses `next-mdx-remote` to render this content.
