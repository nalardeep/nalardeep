Kamu punya ide aplikasi tapi tidak mau mulai dari nol? **Vibe coding** adalah pendekatan baru di mana kamu menjelaskan ide dalam bahasa manusia kepada AI, lalu AI yang mengerjakan kodenya. Istilah ini dipopulerkan oleh Andrej Karpathy.

Alih-alih menulis kode baris demi baris, kamu bertindak sebagai pengarah strategi. Hasilnya? Prototyping jauh lebih cepat, bahkan untuk non-programmer.

Jika tertarik dengan cara menulis prompt yang efektif, baca juga [Prompting Engineering Techniques](/posts/prompting-engineering-technique).

---

## Daftar Tools Vibe Coding

### Cursor & Windsurf — IDE dengan AI

Dua IDE terbaik untuk developer profesional. Keduanya berbasis VS Code dengan integrasi AI canggih.

| Fitur | Cursor | Windsurf |
|-------|--------|----------|
| Harga | $20/bulan | Free + Premium |
| Keunggulan | Familiar seperti VS Code | Cascade flow lebih agresif |
| Best untuk | Developer yang ingin kontrol penuh | Developer yang ingin AI lebih aktif |

### Replit Agent — Full-Stack dari Browser

Platform all-in-one. Deskripsikan apa yang mau dibangun, AI akan membuat kode, setup database, dan deploy otomatis. **Cocok untuk pemula mutlak.**

### Bolt.new & Lovable — Prototipe Web Cepat

- **Bolt.new**: Zero setup, langsung buka browser, preview real-time. Ideal untuk iterasi cepat.
- **Lovable**: UI lebih polished, kode output production-ready. Ideal untuk app yang mau langsung deploy.

### v0.dev — Komponen UI

Tool dari Vercel untuk menghasilkan komponen React + Tailwind CSS. Deskripsikan komponen, dapatkan kode yang bisa langsung di-copy ke proyek Next.js.

## Pilih yang Mana?

| Kebutuhan | Tool Rekomendasi |
|-----------|------------------|
| Developer profesional | Cursor atau Windsurf |
| Tidak bisa coding sama sekali | Replit Agent |
| Prototipe web app cepat | Bolt.new atau Lovable |
| Komponen UI untuk proyek existing | v0.dev |

---

## Tips Vibe Coding

1. **Iterasi, jangan tebak** — Pecah permintaan jadi kecil-kecil, bukan satu prompt besar.
2. **Gunakan checkpoint** — Pastikan bisa rollback jika AI salah arah.
3. **Review kode** — Jangan langsung percaya 100%, terutama bagian keamanan dan error handling.

---

## Pertanyaan Umum

### Vibe coding bisa menggantikan developer?

Untuk prototyping dan MVP, ya. Untuk sistem production berskala besar, tetap butuh developer yang paham arsitektur.

### Berapa biayanya?

Banyak tool punya free tier: **Bolt.new** dan **v0.dev** gratis untuk mulai. **Cursor** dan **Lovable** mulai $20/bulan.

### Kode yang dihasilkan bisa dipakai di produksi?

Ya, terutama **Lovable** dan **v0.dev** yang menghasilkan kode React + Tailwind CSS bersih.
