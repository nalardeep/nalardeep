# Cara Mendapatkan API LLM Gratis GLM 5.2 Via Cloudflare

Halo sobat nalar! Akhir-akhir ini mimin lagi semangat-semangatnya eksplorasi berbagai API LLM gratis yang bisa dipakai untuk ngoprek-ngoprek project. Nah, kali ini mimin nemu satu lagi yang sayang banget kalau dilewatkan — **GLM 5.2 dari Zhipu AI** yang bisa diakses gratis lewat Cloudflare Workers AI.

GLM 5.2 ini model yang cukup mumpuni buat berbagai tugas NLP kayak generate teks, summarization, sampai code completion. Dan yang bikin mimin excited, bisa diakses tanpa perlu ngeluarin duit sama sekali.

Sebelum kita mulai, ada dua hal yang perlu disiapkan:
1. **Akun Cloudflare** — buat dapetin API Key-nya. Tenang, gratis dan nggak perlu kartu kredit.
2. **OpenCode** — tools coding yang akan kita pakai buat nyobain API Key-nya.

Kalau udah siap, langsung gas aja!

---

## Tahap 1: Mendaftar Akun Cloudflare

Buat yang belum punya akun Cloudflare, tenang aja. Prosesnya cuma beberapa menit:

1. Buka browser dan kunjungi [https://dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)
2. Masukkan alamat email dan password, atau langsung login pake Google/Apple/GitHub kalau mau lebih cepet
3. Centang checkbox verifikasi, lalu klik **Create Account**
4. Cek email masuk, klik link verifikasi dari Cloudflare
5. Selesai! Akun Cloudflare siap dipake.

> **Catatan dari mimin:** Jangan lupa verifikasi emailnya ya, karena tanpa itu kita nggak bisa lanjut ke langkah berikutnya.

## Tahap 2: Install OpenCode

OpenCode ini tools koding berbasis AI yang menurut mimin lumayan oke buat dicoba. Cara installnya beda-beda tergantung sistem operasi:

### Windows

Ada beberapa cara, pilih aja yang paling gampang buat kamu:

**Pakai winget (mimin rekomendasiin ini):**
```bash
winget install -e --id SST.opencode
```

**Atau pakai scoop:**
```bash
scoop install opencode
```

**Atau via npm:**
```bash
npm i -g opencode-ai@latest
```

**Atau kalau pake WSL2 (ini yang paling stabil katanya):**
```bash
# Install WSL2 dulu
wsl --install
# Restart komputer, lalu:
curl -fsSL https://opencode.ai/install | bash
```

### macOS

**Pakai Homebrew (recommended):**
```bash
brew install anomalyco/tap/opencode
```

**Atau pake curl:**
```bash
curl -fsSL https://opencode.ai/install | bash
```

**Atau via npm:**
```bash
npm i -g opencode-ai@latest
```

Setelah selesai, cek dulu apakah sudah terinstall dengan benar:

```bash
opencode --version
```

Kalau muncul nomor versi, berarti udah siap dipake.

## Tahap 3: Dapetin API Key Cloudflare Workers AI

Nah, ini bagian intinya. Setelah akun Cloudflare siap, ikuti langkah-langkah ini:

1. Login ke dashboard Cloudflare
2. Di menu **Build**, pilih **AI** lalu cari bagian **Workers AI**
3. Pilih **Rest API** — nanti kamu bakal liat **Account ID**. Salin dan simpan dulu, ya.
4. Scroll dikit, cari **Create a Workers AI API Token**
5. Isi nama Token-nya (misal: "GLM Testing"), lalu klik **Create API Token**
6. Muncul deh API Token-nya. Langsung copy dan simpan di tempat aman.

Mimin saranin, simpan dua informasi ini di file `.env` atau note pribadi — **Account ID** dan **API Token**. Jangan sampai hilang, soalnya kita bakal butuh dua-duanya.

---

## Tahap 4: Cobain API Key di OpenCode

Sekarang waktunya eksekusi. Setelah OpenCode terinstall dan API Key udah siap, kita coba connect:

1. Buka terminal atau PowerShell
2. Ketik `opencode` buat menjalankan programnya
3. Begitu masuk, ketik perintah **/connect**
4. Di daftar provider yang muncul, cari dan pilih **Cloudflare Workers AI**
5. Masukkan **Account ID** dan **API Token** yang tadi udah disimpan
6. Kalau berhasil, langsung bisa dipakai buat ngobrol-ngobrol sama model GLM 5.2

Waktu mimin pertama kali nyobain, mimin langsung kaget — responsnya lumayan cepet buat model yang diakses gratis. Nggak kalah sama model-model berbayar yang pernah dicoba.
