## Tutorial set up n8n di vps DigitalOcean

1. Lakukan pencarian di google dengan kata kunci n8n DigitalOcean
2. Selanjutnya di laman marketplace digitalocean, klik **Create n8n Droplet**.
![n8n droplet](/assets/blog/cara-hosting-n8n-di-VPS/n8n-droplet.webp "n8n droplet")
3. Maka akan muncul halaman mengenai spesifikasi VPS yang akan dipakai untuk n8n tersebut. Disini mimin pakai rekomendasi dari digitalocean saja, yang dimana total penggunaan kredit sekitar $32 untuk perbulannya. Teman-teman juga bisa melakukan custom OS dan imagesnya.
![Create droplet](/assets/blog/cara-hosting-n8n-di-VPS/create-droplet.webp "n8n droplet")
4. Sebelum membuat droplet tersebut, kita perlu menentukan SSH Key yang akan digunakan. Klik Select an SSH Key.
5. Kemudian pilih **Add an SSH Key**.
